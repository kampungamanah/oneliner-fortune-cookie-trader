# oneliner-fortune-cookie-trader

A fortune cookie, cracked open at 3am for a trader whose wallet just got emptied: the classic "tall, dark stranger" fortune, except the stranger is the margin call — and it already took everything.

`main.ts` writes that line to `/output/entry.txt`:

> You will soon meet a tall, dark stranger: your margin call. It already took everything you own.

## Run it

    node main.ts

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` if that variable is set, and to `/output/entry.txt` otherwise — just the line itself, no trailing newline, 95 characters, 17 words.
